# 🐞 BUG: Игра не запускается

## 📌 Описание
 Игра не запускается без режима совместимости с Windows XP(pac 2) 

---

## 🧭 Окружение
- ОС: Windows 11
- Версия игры: .kkrieger (Beta)
- Режим запуска: (обычный / совместимость / админ)
- Устройство: PC

---

## 🔁 Шаги воспроизведения
1. Установить игру
2. Запустить игру
3. Появляется черный экран, идет изменение разширения, после чего игра вылетает
